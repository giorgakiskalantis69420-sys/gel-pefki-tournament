# Τουρνουά 1ο ΓΕΛ Πεύκης

Next.js (App Router) εφαρμογή για σχολικό τουρνουά **3v3 Μπάσκετ** και **4v4 Πετοσφαίρισης**.

## Εκκίνηση

```bash
npm install
npm run dev
```

Άνοιξε [http://localhost:3000](http://localhost:3000).

## Σελίδες

- `/` — Δήλωση ομάδας
- `/brackets` — Κλήρωση και brackets
- `/teams` — Λίστα ομάδων και ρόστερ

Δεδομένα αποθηκεύονται στο **localStorage** ξεχωριστά ανά άθλημα.
